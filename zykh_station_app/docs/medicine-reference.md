# 家庭药柜说明资料来源

## 使用边界

`medicine_repository.py` 内 23 项固定药品的“功能主治/适用范围”和“用法用量/使用方法”来自生产企业公开说明书、药品监管部门说明书范本或可核验的药品说明资料。页面使用“药品说明书参考”标识，并始终要求在使用前核对当前实物包装。

这些文字用于家庭药柜信息展示和安全核验，不替代医生诊断、处方或药师指导。处方药、抗菌药、儿童用药、孕期用药及肝肾功能异常人群必须按已有处方或专业人员指导使用。

固定资料版本为 `verified-label-reference-v1`。版本升级只更新名称仍与固定清单一致的药品说明字段，不重置仓位、库存、条码或管理员改名后的药品资料。

## 维护方式

1. 更换生产厂家、规格或剂型时，不沿用原资料，先在设置页更新基础信息。
2. 系统会将基础信息改变后的说明资料标为待核验；管理员需对照新包装说明书确认。
3. 动态识别或云端补全只能生成待核验草稿，不能覆盖已经核对的固定说明资料。
4. 如实物说明书与本地资料不一致，以实物说明书和医生、药师指导为准。
