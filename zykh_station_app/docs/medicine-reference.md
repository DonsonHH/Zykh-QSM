# 站点药柜说明资料来源

## 使用边界

`medicine_repository.py` 内已核验药品的“功能主治/适用范围”和“用法用量/使用方法”来自生产企业公开说明书、药品监管部门说明书范本或可核验的药品说明资料。页面使用“药品说明书参考”标识，并始终要求在使用前核对当前实物包装。3 号和 13 号已通过用户提供的商品条码联网匹配产品身份、规格与批准文号；有效期采用用户提供的当前库存批次信息。

这些文字用于站点药柜信息展示和安全核验，不替代医生诊断、处方或药师指导。处方药、抗菌药、儿童用药、孕期用药及肝肾功能异常人群必须按已有处方或专业人员指导使用。

固定身份版本为 `home-real-cabinet-v8-fixed-catalog`，安全资料版本为 `database-safety-facts-v5-detailed-fixed-catalog`。23 个固定仓都参与问询安全评估；库存、有效期、处方资格和实时冲突仍可使某项不进入最终候选。版本升级只定向替换完整匹配旧内置基线的 3 号和 13 号身份，并保护管理员改过的标签内容；不会清空管理员库存、扫码药品或其他药品的既有用药计划。被替换旧药对应的计划会停止，必须在核验新药后重新建立，绝不会自动继承为另一种药。

2 号仓当前缺少可区分多维元素片（29）与（29-II）的包装批准文号。为满足演示药柜的重复成分拦截，固定清单暂按两种常见配方的保守并集记录维生素和矿物质关键词；这会偏向多拦截而不是漏拦截，不能替代实物包装确认。更换该仓产品时仍按动态药品规则回到待核验状态。

## 维护方式

1. 更换生产厂家、规格或剂型时，不沿用原资料，先在设置页更新基础信息。
2. 系统会将基础信息改变后的说明资料标为待核验；管理员需对照新包装说明书确认。
3. 动态识别或云端补全只能生成待核验草稿，不能覆盖已经核对的固定说明资料。
4. 如实物说明书与本地资料不一致，以实物说明书和医生、药师指导为准。
